=====================================================================
J~Net App Store — Instructions of use
=====================================================================

PORT
----
The store server runs on port 8090 by default.

  - Server port: 8090
  - Reverse proxy / static domain apps.jnetai.com  ->  127.0.0.1:8090
  - Override the port with:  PORT=9000 ./start.sh   or   ./start.sh --port 9000

The Android app connects to https://apps.jnetai.com by default (changeable in
the app's About screen -> "Change Store URL").


SERVER — SETUP (Ubuntu/Debian)
------------------------------
  ./setup.sh                 # installs Node.js (>=18), npm deps, folders
  ./setup.sh --port 8090     # choose a different port
  ./setup.sh --service       # also install a systemd service (needs sudo)

  Options:
    --port N          port to use (default 8090)
    --user NAME       admin panel username (default admin)
    --password PASS   admin panel password (default: randomly generated)
    --service         install + enable systemd service "jnet-app-store"
    -h, --help        show help

  setup.sh generates a random admin password on first run and prints it in the
  terminal. Change it later from the admin panel (/admin -> Change admin password).


SERVER — START
--------------
  ./start.sh                 # starts the server on port 8090
  ./start.sh --port 8090     # explicit port
  ./start.sh --user admin --password 'secret'

  Then open:
    http://<server-ip>:8090/          public store page (all enabled apps)
    http://<server-ip>:8090/admin     admin editor (HTTP Basic login)
    http://localhost:8090/api/apps    public catalog JSON used by the app

  The admin password is generated randomly during ./setup.sh and shown in the
  terminal. You can change it from inside the admin panel (Change admin
  password section). Credentials live in server/data/settings.json (mode 0600).

  With systemd (if installed via ./setup.sh --service):
    sudo systemctl start jnet-app-store
    sudo systemctl stop jnet-app-store
    sudo systemctl restart jnet-app-store
    sudo systemctl status jnet-app-store


ADMIN PANEL (edit the store) — /admin
-------------------------------------
  - Add an app via a GitHub link: paste the repo/release URL and click
    "Resolve latest" to fetch the latest release tag and .apk asset.
  - Add an app by uploading an APK file (max 250 MB, .apk only).
  - Enable/disable apps (only enabled apps appear on the public store page and
    in the app catalog).
  - Upload a custom app icon (PNG only) — saved as "<App-Name>.png" in
    server/images/ and served at /images/<App-Name>.png.
  - Edit or delete existing entries.
  - Change the admin password from inside the panel (logged in).
  - Catalog is saved to server/data/store.json; uploaded APKs live in
    server/uploads/ and are served at /apk/<file>.

PUBLIC STORE PAGE — /
----------------------
  - Dark, centred theme listing all enabled apps with icon, name, version,
    source badge and description.
  - Live inline search bar at the top; the clear (X) icon resets the filter.
  - Every app uses the default icon unless an image exists at
    server/images/<App-Name>.png (uploaded by an admin).
  - Dark scrollbars are used whenever scrolling is needed.


NGINX REVERSE PROXY (apps.jnetai.com -> :8090)
----------------------------------------------
  server {
      listen 443 ssl;
      server_name apps.jnetai.com;
      ssl_certificate     /etc/letsencrypt/live/apps.jnetai.com/fullchain.pem;
      ssl_certificate_key /etc/letsencrypt/live/apps.jnetai.com/privkey.pem;
      client_max_body_size 260m;
      location / {
          proxy_pass http://127.0.0.1:8090;
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;
      }
  }


ANDROID APP (build + release)
-----------------------------
  - Prime directive: build on GitHub, never locally.
  - Push a tag to trigger the signed release build:
      git tag vX.Y.Z && git push origin main --tags
  - GitHub Actions workflow: .github/workflows/release.yml
  - Release asset: J~Net-App-Store.apk  (GitHub stores it as J.Net-App-Store.apk
    because it sanitises the "~" character).
  - Release page: https://github.com/jnetai-clawbot/JNet-App-Store/releases
  - Local APK copy is placed in the apk/ folder.
  - Same keystore (jnet-app-store-keystore.jks, alias "appstore") is used for
    every build so updates install over the top without uninstalling.


DIAGNOSTICS
-----------
  - Server logs every request and failure with an ERR-* code to stdout and to
    server/logs/store.log (kept permanently).
  - Android app keeps permanent DebugLogger + ErrorHandler diagnostics with
    ERR-* codes and stack traces.
